# Standing rule: Use the right plugin/skill for each situation

For every non-trivial task, use the plugin(s) and skill(s) that fit the
case. Do NOT use all plugins at once — match the tool to the task. Process
skills come first (they set the approach), then implementation skills carry
it out. Always announce which skill/plugin is being used and why
("Using `<plugin>:<skill>` to …"). Skip the heavy workflow only for trivial
one-off actions (a typo fix, a quick question).

The full plugin/skill decision table (which plugin, which sub-skill, when)
lives separately in `.claude/skills/skill-routing.md` — this rule is the
mandate to consult and follow that table, not a duplicate of it.
